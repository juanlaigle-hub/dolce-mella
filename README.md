# Dolce Mella

Página de la marca de chips de manzana deshidratada de Frutas Stelzer (Villa Regina, Alto Valle de Río Negro).

Es un sitio estático: `index.html` y las fotos. Se publica con GitHub Pages desde la rama `main`.

- El nombre de la marca se cambia en una sola línea: `var BRAND = "..."` dentro de `index.html`.
- Las experiencias de ejemplo (usuarios `_demo`) están en la lista `DEMO` del mismo archivo.
